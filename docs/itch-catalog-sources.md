# GameForge Cloud Play: itch.io catalog sources

GameForge links to the official creator-hosted itch.io pages. The game itself remains hosted and played on itch.io; GameForge does not copy, mirror, or rehost third-party game files.

## Added browser-play titles

- **Adventures With Anxiety!** — Nicky Case. Official page: <https://ncase.itch.io/anxiety>. The page identifies it as released HTML5, rated 4.9/5 from 7,369 ratings, and tags it Visual Novel, Comedy, Mental Health, and Narrative.
- **We Become What We Behold** — Nicky Case. Official page: <https://ncase.itch.io/wbwwb>. The page identifies it as released HTML5, rated 4.8/5 from 8,809 ratings, and states that the game is open source with public-domain code and art. It is tagged Comedy, Dark Humor, and Experimental.
- **Friday Night Funkin'** — ninjamuffin99, PhantomArcade, The Funkin' Crew, Inc. Official page: <https://ninja-muffin24.itch.io/funkin>. The page identifies it as an HTML5 rhythm game, rated 4.7/5 from 12,388 ratings, with keyboard/gamepad controls and an Apache 2.0 code license; assets remain credited to the creators.

## Integration policy

Each catalog item stores the official itch.io URL as its `playUrl`, is labeled `ITCH.IO` / `BROWSER READY`, and opens in a new tab with `noopener noreferrer`. The Cloud Play UI also keeps the creator/source name visible so visitors understand where the game is hosted.

itch.io's HTML5 documentation explains that HTML games are played in-browser through an embedded iframe on the creator's project page and that the uploaded project must include an `index.html`: <https://itch.io/docs/creators/html5>.
