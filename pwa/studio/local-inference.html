Inference stays on this device.

The Studio runs WebLLM in a browser worker using WebGPU. It does not call a hosted chat-completions API and requires no inference API key.

First load and offline use

The first model load fetches quantized weights from Hugging Face and a matching WebGPU model library from the WebLLM project. WebLLM's default Cache API stores artifacts per origin. Subsequent use can work offline while that browser cache remains available; browser storage may be cleared or evicted. Use HTTPS or localhost and a browser with WebGPU.

Data boundary

Prompt and response text stay in the current page and worker, and conversations are memory-only. No prompts or outputs are written to storage. Only the model artifacts are fetched remotely. Generated game.ts is shown as text, never evaluated. The preview renders only validated, bounded JSON descriptions.
